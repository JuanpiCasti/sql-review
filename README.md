# Postgres Study

A personal reference site covering PostgreSQL 16+ in depth. Not a tutorial — assumes familiarity with SQL and targets engineers who want to understand how Postgres works, not just how to use it.

Each chapter includes annotated examples with real result tables, callouts on common pitfalls, and a cheat-sheet recap.
